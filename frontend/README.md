# CC98 AI+ 浏览器插件

当前版本：`0.1.6`

CC98 AI+ 为 CC98 增加两项能力：

- **AI 搜索**：搜索真实帖子和回复，生成带来源链接的总结。
- **订阅提醒**：持续关注新帖，并通过插件通知列表、邮箱或钉钉接收提醒。

AI 搜索使用用户自己的 CC98 登录状态和 LLM API Key，二者都只保存在本地浏览器中。订阅提醒由项目后端完成，需要先使用浙大邮箱验证码登录。

## 安装

1. 下载并解压仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择仓库中的 `frontend/` 目录。
5. 打开或刷新 [CC98](https://www.cc98.org)。

安装成功后，CC98 页面右下角会出现一个**带放大镜和星芒图标的圆形入口**。入口可以拖动，位置会保存在当前浏览器中；点击入口即可打开插件面板。

如果入口没有出现，请先在扩展程序管理页确认插件已启用，然后重新加载插件并刷新 CC98 页面。安装插件之前已经打开的页面不会自动注入界面。

## 配置 AI 搜索

点击浏览器工具栏中的 CC98 AI+ 图标，或在插件面板的「设置」中打开完整设置页。填写：

- 服务协议：OpenAI 兼容或 Anthropic；
- Base URL；
- 模型名称；
- API Key。

默认配置使用硅基流动的 OpenAI 兼容接口：

| 项目 | 默认值 |
| --- | --- |
| Base URL | `https://api.siliconflow.cn/v1` |
| 模型 | `Qwen/Qwen2.5-14B-Instruct` |
| Max Tokens | `0`，表示不主动限制 |

其他 OpenAI 兼容服务也可以使用。首次保存新的服务地址时，浏览器可能会请求访问该域名的权限。请先点击「测试连接」，确认成功后再点击页面底部的「保存设置」。

API Key 只会发送给用户填写的 AI 服务地址，不会发送到 CC98 AI+ 后端。生成总结时，选中的帖子正文和回复也会发送到该 AI 服务地址；含“请勿转载”“禁止外传”等声明的内容会先被过滤。

## 使用 AI 搜索

1. 点击 CC98 页面右下角的圆形入口，或按 `Ctrl+Shift+K`。
2. 在「搜索」页输入自然语言问题，例如「竺院保研需要注意什么」。
3. 点击「搜索」或按回车。

搜索会依次完成：拆分关键词、检索 CC98、筛选主题、阅读回复、生成总结。结果包含使用的关键词、结构化总结和可直接打开的来源帖子。

在 CC98 页面中按 `Alt+Shift+N` 可以直接打开通知页。该组合键避开了浏览器用于打开无痕窗口的 `Ctrl+Shift+N`。

完整设置页中的「搜索预算」可以控制关键词数量、每个关键词的结果数、读取的主题数和楼层数。一轮搜索最多访问 CC98 20 次，两轮完整搜索至少间隔 45 秒；短期内存缓存会减少重复访问。

## 使用订阅提醒

### 登录

打开插件面板的「设置」，输入浙大邮箱并获取 6 位验证码。验证成功后，才能管理订阅、通知渠道和通知历史。

### 添加订阅

在「订阅」页填写一条表达式。规则如下：

- 空格表示「且」；
- 半角 `/` 表示「或」；
- 每个关键词至少 2 个字符；
- 表达式总长度不超过 255 个字符。

示例：

| 表达式 | 含义 |
| --- | --- |
| `实习` | 帖子中出现「实习」 |
| `大一/新生 军训` | 出现「大一」或「新生」，并且出现「军训」 |
| `微积分/微甲/vjf 历年卷 资料` | 三个课程称呼命中任意一个，同时还要出现「历年卷」和「资料」 |

一个账号最多创建 10 条订阅，暂停的订阅也计入总数。暂停后不会继续匹配新帖，但可以随时恢复。

### 设置通知渠道

插件支持两种外部提醒：

- **邮箱**：填写接收邮箱和主题前缀；发信账号由后端部署方统一配置。
- **钉钉机器人**：填写自定义机器人的 Webhook；如果机器人启用了加签，还需填写 `SEC` 开头的 Secret。

通知间隔表示「攒一批再发送」。后端固定周期扫描新帖，匹配结果会先进入通知列表，到达用户选择的通知间隔后，再合并发送到已启用的渠道。

完整设置页和插件面板都可以管理通知渠道。保存后可以发送测试消息，确认配置是否有效。

### 查看通知

「通知」页会显示命中的帖子、匹配原因、创建时间和投递状态。通知列表最多每 60 秒主动刷新一次；打开页面时会优先使用最近的缓存，避免重复请求。

同一篇帖子命中多条表达式时，插件通知列表只保留一条帖子记录，并显示全部命中的表达式。邮箱和钉钉消息会按照「一条表达式对应哪些帖子」分组展示。

## 主题与界面

插件会读取当前 CC98 主题的背景色、文字色和强调色，并同步到站内面板、工具栏弹窗和完整设置页。切换 CC98 主题后，刷新页面即可更新插件配色。

面板和右下角入口都可以拖动，位置保存在浏览器本地。

## 校外访问

插件支持以下方式访问 CC98：

- 使用 RVPN / ZJU Connect 后直接打开 `https://www.cc98.org`；
- 通过学校 WebVPN 打开 CC98。

WebVPN 环境下，插件会转换 CC98 API 地址和原帖链接。RVPN / ZJU Connect 只影响访问校内网络，不是安装插件的条件。

## 更新插件

开发者模式加载的插件不会自动从 GitHub 更新。获取新版后：

1. 用新版 `frontend/` 内容替换原目录；
2. 在扩展程序管理页点击 CC98 AI+ 卡片上的「重新加载」；
3. 刷新已经打开的 CC98 页面。

## 常见问题

### 页面右下角没有入口

确认插件已启用并允许访问 CC98，然后重新加载插件并刷新页面。WebVPN 下还需要确保当前页面确实是 CC98。

### 打不开完整设置页

先在扩展程序管理页重新加载插件，再刷新 CC98。也可以直接点击浏览器工具栏中的 CC98 AI+ 图标进入设置。

### AI 服务提示 Key 无效

确认 API Key、Base URL 和模型属于同一个服务商。中转服务的 Key 需要搭配该服务自己的地址。

### 搜索很慢

CC98 搜索接口有请求间隔限制，插件还需要逐个读取帖子和回复。在完整设置页调低主题数或每个主题读取的回复数，可以缩短等待时间。

### 订阅添加失败

检查表达式是否符合规则：空格是「且」，半角 `/` 是「或」，斜杠两侧都必须有关键词，每个关键词至少 2 个字符。相同表达式不能重复创建。

### 收不到外部通知

确认订阅处于启用状态、通知渠道已启用且测试消息发送成功。即使外部推送失败，已经匹配的帖子仍会保留在插件通知列表中。

## 开发说明

```text
frontend/
├── manifest.json
├── vendor/
└── src/
    ├── background/       Service Worker、网络代理和扩展消息
    ├── content/
    │   ├── lib/          存储、网络、鉴权和 API 客户端
    │   ├── pipeline/     AI 搜索流程
    │   └── ui/           悬浮入口、面板、主题同步和各功能页
    ├── pages/
    │   ├── options/      完整设置页
    │   └── popup/        工具栏弹窗
    └── shared/           常量和共享主题色
```

前端是 Manifest V3 原生扩展，无需构建。修改后重新加载扩展即可测试。

## 安全边界

- CC98 Token 保存在 `chrome.storage.session`，关闭浏览器后清除，只用于访问 CC98 API。
- LLM API Key 保存在 `chrome.storage.local`，只发送到用户配置的 AI 服务地址。
- 项目后端不接收用户的 CC98 Token 和 LLM API Key。
- 项目后端只增量检查最新帖子，不回溯历史内容，不下载图片或附件，也不长期保存帖子正文和回复。
- 浙大邮箱、订阅、通知渠道和通知历史保存在 Watch 后端，用于持续扫描和推送。
- 通知渠道中的 Secret 在普通接口响应和错误信息中会被隐藏。

后端部署和接口说明见 [backend/README.md](../backend/README.md) 与 [docs/deployment.md](../docs/deployment.md)。
